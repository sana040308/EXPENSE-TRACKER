# Expense Tracker

A simple and user-friendly Expense Tracker built with HTML, CSS, and JavaScript to practice front-end web development and make expense management easier.

## About the Project

The Expense Tracker is a personal project created to strengthen my skills in building interactive web applications. It focuses on creating a clean interface and using JavaScript to add functionality to a web page.

## Built With

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality

## Features

- Simple and clean user interface
- Responsive layout 
- Expense tracking functionality 

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/sana040308/EXPENSE-TRACKER.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
